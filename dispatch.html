This page does not check your maths. It checks structure — missing hints, an estimate range that doesn’t contain your answer, answer forms that aren’t actually equal. It cannot tell you that 3/4 of 8 isn’t 5. For an independent maths check, run the file through /add-problems in Claude Code afterwards.
